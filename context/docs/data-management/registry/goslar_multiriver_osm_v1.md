# Goslar expanded OSM input snapshot

Classification: LOCAL_DATA; reusable locally. Product: live OpenStreetMap Overpass snapshot, access 2026-09-14. Source: https://overpass-api.de/api/interpreter (fallback https://overpass.kumi.systems/api/interpreter). Licence: ODbL, OpenStreetMap contributors; no account required.

Study rectangle EPSG:32632: 555411, 5737748, 615576, 5792557. Source rectangle adds 3000 m on every side; WGS84 envelope is conservatively transformed with densified edges. Intended use: expanded road proximity and original seven-category infrastructure proxies. The fetched window is finite and is not evidence of completeness outside that window. Current snapshot differs from original snapshot date; temporal changes must be separated from boundary expansion effects where possible.

Acquisition command: `.venv/bin/python bin/acquire/pull_multiriver_osm.py`. Destination: `data/raw/goslar_multiriver_osm_v1/`; raw queries/responses and manifest kept, partial files under `data/tmp/goslar_multiriver_osm_v1/`. Expected download: tens MB. Facilities preserve original class filter and tag precedence; roads retain all highway ways, including paths. Checksums, sizes, server timestamps, exact requests and selected counts are written to `source_manifest.json` after download.

Full-window roads requests timed out; road requests use 16 tiles, at most two in flight, with OSM identifier deduplication. Documented current alternative endpoint: https://overpass.private.coffee/api/interpreter (OpenStreetMap Wiki public instance list https://wiki.openstreetmap.org/wiki/Overpass_API, checked 2026-09-14). Retry backoff is at least 60 seconds and respects numeric Retry-After.
