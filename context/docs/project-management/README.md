# IFPM Project Management Notes

This folder contains internal planning artifacts for the IFPM flood-risk modelling work.

- `task_progress_board.md`: current progress, next tasks, blockers, and verification gates.
- `prototype_study_slice_decision.md`: first controlled prototype scope decision.
- `real_data_preprocessing_design.md`: real-data grid, resampling, aggregation, CRS, and NoData
  design before downloads.
- `real_data_execution_preflight_gate.md`: cross-dataset go/no-go gate before controlled
  real-data download.
